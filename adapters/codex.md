# Harness dialect: Codex

- Skills live in `~/.codex/skills/`. "Invoke the Skill tool with `skill: X`" means
  read `~/.codex/skills/X/SKILL.md` and follow it.
- Memory: the `mind` MCP protocol below applies.
- Subagents: Codex has no `Agent` tool. Where section 8 says to delegate, either
  run the work inline or start a separate `codex exec` run.
