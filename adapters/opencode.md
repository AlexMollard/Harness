# Harness dialect: opencode

- Skills live in `~/.config/opencode/skills/` plus any path in the config
  `skills.paths` array. "Invoke the Skill tool with `skill: X`" means read that
  skill's `SKILL.md` and follow it.
- Commands live in `~/.config/opencode/commands/`.
- Memory: the `mind` MCP protocol applies.
- Subagents: no `Agent` tool; run section 8's delegation inline.
