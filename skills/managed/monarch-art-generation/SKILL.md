# Monarch art generation

Artwork lives in `app/src/main/res/drawable-nodpi/art_*.png` and is generated by
`tools/art.py` — gemini-3.1-flash-image through omp's `google-antigravity`
provider, transported via headroom on `127.0.0.1:8787`. Auth comes from
`omp token google-antigravity`; no secret lives in the repo.

## Generate

```bash
python tools/art.py --style ink --alpha --size 512 "<subject only>" -o .tmp/art_<name>.png
```

- `--style` is a contract (`ink`, `line`, `woodcut`). Never bake style words into
  the prompt; add or edit a style in the script instead, so screens cannot drift.
- `--alpha` is required for anything sitting on a panel.
- Prompt the SUBJECT only, e.g. `"a closed leather ledger with a ribbon marker"`.

A run takes ~15s and prints chroma / contrast / backdrop / film checks.

## The two traps

**1. The paper film.** Density keying (`ink_to_alpha`) turns darkness into
opacity, so blank paper lands at alpha 3-24 instead of 0. Measured on shipped
art: **78-91% of the canvas**. Invisible in isolation, and plainly visible on a
real device as a lighter box exactly the size of the image — this is what the
owner reported as "I can see the bg of it against the dark bg".

`cut_paper_film()` now removes it at source (soft knee: `alpha <= 20 -> 0`, ramp
to 40, chosen from the alpha histogram's gap between film and strokes). Verify
any image independently:

```python
from PIL import Image
h = Image.open(p).convert("RGBA").split()[3].histogram(); tot = sum(h)
print(f"film {100*sum(h[3:25])/tot:.1f}%  ink {100*sum(h[41:])/tot:.1f}%")
```

Healthy output: film < 3%, most pixels at alpha 0.

**2. The model draws its own frame.** A faint sketched rectangle sits inside the
margin and reads as the same box. Crop ~7% off each edge before shipping:

```python
m = int(min(w, h) * 0.07); im = im.crop((m, m, w - m, h - m)).resize((512, 512))
```

## Do not trust the audit alone

`backdrop_audit` originally checked only opaque corners and >55% opaque
coverage, so a canvas entirely at alpha 3-24 passed as "transparent". It now also
fails above 5% film — but the histogram above is the check that settles it.

## Wire and verify

Empty states take `Image(painterResource(R.drawable.art_*), contentDescription = null,
modifier = Modifier.size(...).alpha(0.55f))`. Imports usually missing:
`androidx.compose.foundation.Image`, `ui.res.painterResource`, `ui.draw.alpha`,
`foundation.layout.size`, `com.monarch.app.R`.

Then look at it on a device — the film was invisible in every static check and
obvious on screen. **Pin instrumented Gradle runs with
`ANDROID_SERIAL=emulator-5554`**: the suite calls `pm clear` and deletes
sessions, and the owner's S25 Ultra (`R5GL14GXV3J`) holds real training data.
